快速使用流程

三步建立网络连接，轻量配置，不留冗余步骤。

第一步：获取专属订阅

在用户控制台选定服务方案，复制通用订阅 URL 或直接导出 Clash 格式配置文件。

第二步：导入客户端配置

打开本地客户端，选择新建配置，粘贴订阅链接并点击更新。节点列表将自动列出。

第三步：选择路由规则

将模式切换为“Rule / 规则”模式。浏览器发起网络请求时将自动实现国内外分流。

常见问题解答

关于流量结算、设备上限以及配置更新的说明。

订阅流量是如何计算与重置的？

流量按套餐周期重置。当下行与上行产生数据时计入配额，未用完的流量不结转至下一周期。

超出设备同时在线限制会有什么影响？

系统按 IP 与活跃连接数判定在线设备。超出套餐限制时，较早建立连接的设备可能被断开连接。

节点列表无法更新如何排查？

请核实网络本地 DNS 解析是否正常。若链接提示超时，可尝试切换本地网络或检查订阅链接完整性。

是否支持随时更改或升级套餐？

支持在管理后台直接补差价更换规格。新配额与设备数将在新方案生效后立即更新。
